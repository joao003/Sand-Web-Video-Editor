# English Version

Sand Web Video Editor is a video editing application designed to run directly in the web browser without requiring any installation.

# Features

<img width="1920" height="940" alt="sandwebvideoeditorscreenshotenglish" src="https://github.com/user-attachments/assets/3d3a6d63-dd29-42d0-a9d5-bdb5b2dd17a2" />

* The application was coded in ASP.NET MVC Razor, Blazor WebAssembly, C#, HTML, JavaScript, and CSS
* The application's frontend is built with Bootstrap
* Allows uploading video files (.mp4, .mov, .mkv, .webm, and .avi), image files (.png, .jpg, .jpeg, .webp, and .bmp), and audio/music files (.mp3, .wav, .m4a, .aac, and .ogg) to the collection
* Offers a multi-track timeline to place, edit, and organize videos/images, audios/music, and texts/titles
* Allows changing the properties of the selected timeline item with various options
* Allows exporting the project as an MP4 video at 480p, 720p, or 1080p resolutions
* Video rendering is performed using FFmpeg
* Works on desktops, laptops, smartphones, and tablets, supporting both keyboard/mouse and touchscreen inputs, though using a keyboard and mouse is recommended

# Versão em Português

O Sand Web Video Editor é um aplicativo de edição de vídeo feito para rodar diretamente na navegador da web sem precisar da instalação.

# Recursos

<img width="1920" height="939" alt="sandwebvideoeditorscreenshot" src="https://github.com/user-attachments/assets/751cad6e-9db5-4c6f-9241-f5945f7b7386" />

* O aplicativo foi codificado em ASP.NET MVC Razor, Blazor WebAssembly, C#, HTML, JavaScript e CSS
* O frontend do aplicativo é feito em Bootstrap
* Permite a fazer o upload de arquivo em vídeo (.mp4, .mov, .mkv, .webm e .avi), imagem (.png, .jpg, .jpeg, .webp e .bmp) e áudio/música (.mp3, .wav, .m4a, .aac e .ogg) para coleção
* Oferece o timeline multi-trilha para colocar, alterar e organizar os vídeos/imagens, áudios/músicas e textos/títulos
* Permite a alterar as propriedades do item selecionado de timeline com diversas opções
* Permite a exportar o projeto em vídeo em MP4 com resoluções de 480p, 720p ou 1080p
* A renderização de vídeo é feita através de FFMpeg
* Funciona em desktops, notebooks, smartphones e tablets, tanto teclado e mouse quanto touchscreen. Mas o uso de teclado e mouse é recomendável
